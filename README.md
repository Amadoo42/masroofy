# Masroofy - Budget Management Web App

Masroofy is a personal budget management web application built with Django (MVT architecture). It is designed to help college students track their expenses, calculate a dynamic "Safe Daily Limit," and visualize their spending to avoid exhausting their allowance before the cycle ends.

## 🏗️ Project File Structure

We strictly follow the Django MVT (Model-View-Template) pattern. All business logic and threshold calculations belong in the Models, while Views handle request routing.
